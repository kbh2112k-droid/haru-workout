# 하루운동

걷기, 달리기, 근력 운동, 자전거 운동을 기록하는 작은 웹앱입니다. 오늘의 총 운동 시간과 지난 기록을 확인할 수 있습니다.

## 사용 방법

1. `index.html`을 더블클릭해 인터넷 브라우저로 엽니다.
2. 운동 종류, 날짜, 운동 시간(1~1440분)을 고릅니다.
3. **운동 기록 저장하기**를 누릅니다.

기록은 현재 브라우저의 localStorage에 저장됩니다. 서버로 전송되지 않으며, 다른 컴퓨터·브라우저에서는 보이지 않습니다. 브라우저 데이터를 지우거나 비공개 창을 닫으면 기록이 사라질 수 있습니다. 컴퓨터에서 연 파일과 GitHub Pages 사이트의 기록은 서로 별개입니다. 파일로 직접 열었을 때 저장이 제한되면 GitHub Pages에서 이용하세요.

## GitHub Pages에 올리기

이 폴더의 파일을 GitHub 저장소 맨 위에 올립니다. 저장소의 **Settings → Pages**에서 **Deploy from a branch**, **main**, **/(root)**를 선택하고 저장합니다. `.nojekyll` 파일도 함께 올리세요. 별도 설치나 빌드는 필요 없습니다.

## 파일 안내

- `index.html`: 첫 화면
- `style.css`: 화면 모양
- `app.js`: 운동 기록과 브라우저 저장 기능
- `favicon.svg`: 브라우저 탭 아이콘
- `.nojekyll`: GitHub Pages용 빈 파일
- `.gitignore`: 임시 파일과 비밀 설정의 업로드 방지

기존 Sites·Cloudflare 서버 코드와 전용 설정은 제거했습니다. 기존 서버에 있던 기록은 이 폴더에 포함되어 있지 않으므로 자동으로 옮겨지지 않습니다.
